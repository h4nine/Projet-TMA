À propos du projet

Moodify

Moodify est un site qui permet à l’utilisateur de choisir son émotion du moment afin de générer un univers personnalisé composé d’une playlist, d’une citation, de tags et d’une ambiance visuelle.

Objectif

Offrir une expérience immersive et interactive basée sur l’humeur.

Technologies

HTML pour la structure, CSS pour le design, JavaScript pour le dynamisme.

Fonctionnement

L’utilisateur choisit un mood, le site sauvegarde ce choix et affiche ensuite un résultat personnalisé.

Esprit du projet

Jeune, moderne, esthétique, émotionnel et interactif.

Projet réalisé en HTML, CSS et JavaScript.
